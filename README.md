# Aurona Code

**Create Without Limits.**

A more focused, intuitive, and enjoyable place to build software.

Aurona Code is a code editor designed to help developers focus on what matters most: turning ideas into reality.

We believe great tools should stay out of the way, making software development feel more natural, productive, and enjoyable.
